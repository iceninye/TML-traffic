# 位置模型 (MODEL)

**日期**：2026-10-04 · **版本**：v0.2.0
**依據**：《港鐵屯馬綫實時列車動態定位系統：車務數據分析與運算模型構建報告》

v0.1 用直綫距離 + 兩段固定車速（43 / 65 km/h）倒推位置，**冇計停站時間**，全程只得 57.3 分鐘，
實際係 73–75 分鐘，所以列車成日畫喺 anchor 站隔籬 1–2 個站。v0.2 改用時間表模型。

## 1. 資料：`data/tml-timetable.json`

由 `python3 tools/build_data.py` 生成。

| 項目 | 來源 | 數值 |
|---|---|---|
| 站間軌道距離 | 報告第二章（累積里程，屯門 = 0） | 全綫 56.30 km |
| 站間行車時間（9 段） | TML1100B 平日時間表（報告 3.3 節） | 繁忙 / 非繁忙兩欄 |
| 站間行車時間（其餘 17 段） | 以上 8 段（不含烏溪沙入站）做最小二乘 `t = c0 + c1·m`，再按比例縮放令全綫總和 = 3662 s（繁忙）/ 3756 s（非繁忙） | 標 `"source": "fitted"` |
| 停站時間 | 報告：一般站 22–31 s；美孚 38、紅磡 40、何文田 36 s | 全綫合共 678 s |
| 服務時段／班距 | TML1100B（平日）、TML6090A（星期六）、TML7090（星期日及假期） | 決定用繁忙定非繁忙行車時間，及頂部時段標示 |

**驗證**：非繁忙全程 = 3755 s 行車 + 678 s 停站 = **73.9 分鐘**（實際 73–75 分鐘 ✓）。
OSM 走綫長度 56.26 km（報告 56.30 km ✓）。

## 2. 位置計算：`lib/tml-model.js`

每班車 = 估算器（`mtr-estimate.js`）揀出嘅 anchor 站 + 到站時刻 `dueAt`。
任何時刻 `t` 嘅位置係 `(anchor, dueAt, t)` 嘅純函數：

- **未到 anchor**：由 anchor 向後扣「行車時間 → 上一站停站時間 → 行車時間 …」，扣到邊段就喺邊段。
- **已到 anchor**：先停站，再向前行，逐站加停站時間。
- **站間**：梯形速度曲線（加速 22% → 巡航 → 減速 22%），即報告 5.2 節嘅 S 曲線；起步慢、中段快、入站前減速。
- **繁忙／非繁忙**：按香港時間同星期幾揀行車時間欄（公眾假期當平日處理，已知限制）。
- **短程車**（dest = 大圍／紅磡等）：path 只去到 dest，到站停 40 秒後消失（報告 3.1 節）。
- **秒級到站時間**：用 API 嘅 `time` 減 `curr_time`，唔係淨用整數分鐘 `ttnt`（報告 4.1 節）；兩者相差超過 90 秒先退回 `ttnt`。

估算器串連各站倒數時，亦改用「停站 + 行車」作站與站之間嘅時間差（`setHopModel()`）。

## 3. 平滑：`lib/tml-motion.js`

報告 5.3 節建議用 DTW 做「軟性糾偏」。呢度用一個等效但簡單得多嘅做法：

- 新快照到嘅時候，同一方向、同一目的地、2.6 km 內最近嘅舊列車視為同一班車（保留 id）。
- 新舊位置差記做 `offset`，以時間常數 5 秒指數衰減，**並限制糾偏速度 ≤ 45 m/s**。
- 列車喺畫面上**永遠唔會倒行**：估算落後就原地等，追上先再行。
- 失去觀測嘅列車按最後一次觀測繼續行 25 秒先移除。

## 5. 已知限制

- 上行（往屯門）用下行嘅站間時間（時間表只列咗下行）。
- 公眾假期唔識別，當平日。
- 車廠出車（八鄉、大圍、紅磡停放處）冇獨立模型；估算器喺中途站「突然出現」嘅列車會由該站開始行。
- 冇後端 / WebSocket（報告第六章）：GitHub Pages 係純靜態，瀏覽器直接讀港鐵 API（CORS `*`），每 18 秒一輪。
